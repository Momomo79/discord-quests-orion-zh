## 这是什么

一个跑在 Discord 客户端里的脚本，**不用真的玩游戏、看视频，就能把 Discord 任务（Quests）做完并领到奖励**。

它的原理是读取 Discord 自己的内部模块，让 Discord 以为你正在做任务要求的事，然后等 Discord 把进度记上，并顺手帮你领奖。

## 有什么用

| 用途 | 说明 |
| --- | --- |
| 免操作完成任务 | 挂机即可完成「玩游戏 / 看视频 / 直播 / 参加活动」类任务，坐等发奖 |
| 自动接取与自动领奖 | 无需手动点接取，可选自动领取奖励，省掉反复来回点 |
| 可视化面板 | 可拖拽的控制台，实时看每个任务的进度与中文日志 |
| 奖励筛选 | 按奖励类型（宝珠 / 头像装饰 / 游戏内物品）挑选要跑的任务，并统计可获得的宝珠数 |
| 夜间挂机 | 支持多轮循环 + 随机间隔，睡前挂上，醒来收奖励 |

**支持的任务类型**

| 类型 | 是否可自动完成 |
| --- | --- |
| 看视频 | ✅ |
| 玩游戏 | ✅ 需要桌面客户端 |
| 直播 | ❌ 本工具明确说明无法完成（Discord 会先校验你是否真的在直播且频道里有别人） |
| 运行活动 | ✅ 部分，部分活动有年龄限制或已下架会跳过 |
| 游戏内成就 | ❌ 必须在真实游戏里获得，任何工具都做不到 |

## 怎么用

1. 打开 Discord 桌面客户端
2. 按 `Ctrl + Shift + I` 打开开发者工具 → **Console** 标签页
3. 若提示禁止粘贴，先在控制台输入 `allow pasting` 回车
4. 打开 [`index-zh-CN.js`](index-zh-CN.js)，**全选复制**，粘贴进控制台回车
5. 面板出现在右上角，勾选任务后点「开始」

**快捷键与操作**

| 操作 | 效果 |
| --- | --- |
| `Shift + .` | 显示 / 隐藏面板 |
| 拖动标题栏 | 移动面板 |
| 双击标题栏 | 折叠 / 展开 |
| 停止 | 结束运行并还原所有改动 |
| 隐藏 | 只隐藏面板，脚本继续跑 |

> Discord Stable 默认关闭控制台，需在 `%appdata%/discord/settings.json` 里加
> `{ "DANGEROUS_ENABLE_DEVTOOLS_ONLY_ENABLE_IF_YOU_KNOW_WHAT_YOURE_DOING": true }` 后重启。
> 或者直接用 [Canary](https://canary.discord.com/download)，它默认就开着。

## 出了问题怎么解决

### 快速自查表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 粘贴后什么都没出现 | 粘贴位置不对，或客户端不允许粘贴 | 确认是在 **Console** 标签页；先输入 `allow pasting`；确认脚本整段复制完整（开头是 `(async () => {`） |
| 提示「已在运行中」 | 同一页面已有一个实例 | 没必要重复运行。若面板被隐藏，按 `Shift + .` 调出来 |
| 提示「Discord 未向该客户端下发任务列表」 | Discord 还没加载完任务数据 | 按 `Ctrl + R` 重载 Discord，再重新粘贴运行 |
| 提示「加载 Discord 模块失败」 | 客户端版本更新，内部模块结构变了 | 见下方「模块提取失效」 |
| 面板按钮点了没反应 | 脚本已停止或崩溃 | 重新粘贴运行；崩溃会自动释放锁定并还原补丁，不用刷新页面 |
| 日志疯狂刷「重试」 | 触发限流或服务端临时故障 | 正常现象，脚本会自动退避重试，最多 3 次，不用管 |
| 任务卡片显示「需要人工操作」 | 自动途中失败，需要你介入 | 点卡片上的「领取奖励」或「前往任务页面」手动完成 |
| 自动领奖总失败 | 领奖常会触发验证码 | 关掉「自动领取奖励」，改为手动点卡片上的领取按钮 |
| 任务进度条不动 | 任务本身跑不通 | 看日志里给出的具体原因，通常是有年龄限制、已下架，或本客户端无法驱动 |
| 有弹窗一直弹 | —— | 脚本会自动拦截页面和 iframe 的弹窗，若仍有弹窗说明不是本脚本范围内的问题 |

### 按问题分类

**① 模块提取失效（最常见）**
日志出现「加载 Discord 模块失败」「未找到核心模块」「Vencord 提取遗漏」等，说明 Discord 改了内部结构。
- 装了 Vencord 的话，脚本会自动改用 Vencord 的 Webpack API，成功率更高
- 或者改用 **Canary / PTB**，它们的原生路径通常仍然有效
- 都无效说明还没适配新版本，只能等上游更新（本仓库是汉化版，功能问题需等上游修复）

**② 成就任务被跳过**
日志提示 CSP 拦截、`discordsays.com` 无法访问。Discord 禁止页面直接请求活动后端，需要在下列通道里至少有一个可用：
- **本机中继**：上游发布页提供的 `orion-relay`，跑在 `127.0.0.1:43210`，双击启动并保持窗口打开即可
- **Vencord 插件**：从 Electron 主进程发请求，不受 CSP 限制
- 两种都没有 → 成就任务会被安全跳过，不影响其他任务

**③ 游戏 / 直播任务不动**
- 游戏任务必须有**桌面客户端**，纯网页版会被过滤掉
- 游戏任务 90 秒收不到 Discord 心跳就会带原因中止，这是设计行为，不是卡死
- 直播任务**本来就是坏的**，上游已明确说明，会改走同一任务里的其他可用路径；若该任务只有直播，则跳过

**④ 提示任务权限被暂停 / 封禁**
日志会出现「Discord 已暂停该账号的任务访问权限」或「已封禁任务接取权限，直到 某日期」。
这是 Discord 的风控信号，**脚本会主动停止**，这是保护机制。
**不要**想着绕过去继续跑，等封禁期结束后再用，否则可能升级为更严重的处罚。

**⑤ 活动状态没恢复**
脚本运行时会临时关闭 Discord 的「将当前活动显示为状态消息」，停止后自动还原。
如果中途直接关掉或刷新了 Discord，需要手动到 Discord 设置里重新打开这一项。

**⑥ 想彻底停下**
点面板上的「停止」。脚本会还原所有改过的模块、移除伪造进程、撤销它自己创建的授权。
约 1 秒后清理完成，可以再重新粘贴运行。
